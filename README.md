# 🚀 Portfólio Pessoal — Gabriel Ferreira

Site de portfólio pessoal desenvolvido com **HTML, CSS e JavaScript puro**, sem dependência de frameworks. Apresenta informações sobre formação, habilidades, projetos e formas de contato.

---

## 📋 Seções

- **Sobre Mim** — Apresentação pessoal, interesses e áreas de foco
- **Formação Acadêmica** — Graduação em Ciências da Computação e tecnologias estudadas
- **Portfólio de Projetos** — Cards com links diretos para os repositórios no GitHub
- **Contato** — Formulário de contato com validação + links para redes sociais

---

## ✨ Funcionalidades

- 🌙 **Tema claro/escuro** — alternância com preferência salva no `localStorage`
- ✅ **Validação de formulário** — verificação de campos em tempo real (nome, e-mail, mensagem)
- 📱 **Design responsivo** — adaptado para mobile e desktop
- 🎯 **Navegação suave** — scroll animado entre as seções

---

## 🛠️ Tecnologias Utilizadas

| Camada | Tecnologia |
|--------|-----------|
| Estrutura | HTML5 semântico |
| Estilo | CSS3 (variáveis, flexbox, grid) |
| Interatividade | JavaScript (ES6+) puro |

> Nenhum framework ou biblioteca externa foi utilizado — apenas a tríade padrão da web.

---

## 📁 Estrutura do Projeto

```
Portifolio/
├── index.html    # Estrutura principal e conteúdo
├── styles.css    # Estilos, variáveis de tema e responsividade
└── script.js     # Tema, validação de formulário e interações
```

---

## 🚀 Como Executar

Basta abrir o arquivo `index.html` diretamente no navegador — não é necessário servidor, build ou instalação de dependências.

```bash
# Clone o repositório
git clone https://github.com/escritor2/Portifolio.git

# Abra no navegador
open index.html
```
